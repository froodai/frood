# Contracts

Versioned capability contracts (OpenAPI / JSON Schema) and their conformance tests, for example
`sources.pull@1`, `media.transcribe@1`, `agents.execute@1`, `notify.send@1`.
See [docs/16_platform.md](../docs/16_platform.md) §2–3. Licensed under Apache-2.0 (see `LICENSE`)
so modules implementing them can use any license.

Empty until the first contract lands (milestone M3/M4).

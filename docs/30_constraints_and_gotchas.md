# Ограничения и ловушки, найденные в ресерче

> Это факты внешнего мира, которые меняют дизайн. Ссылки на источники — в [20_component_landscape.md](20_component_landscape.md).

| # | Факт | Влияние на дизайн |
|---|---|---|
| G1 | **ChatGPT:** кастомный MCP подключается только в вебе; на Pro только read/fetch; полный write только на Business / Enterprise / Edu; Plus не упомянут | Сценарий «надиктовал факт в ChatGPT на телефоне → сохранилось» **не гарантирован**. Нужен независимый канал capture (Telegram, iOS Shortcut, PWA). ChatGPT на личном плане — в основном для чтения памяти |
| G2 | **Claude:** custom connectors есть и на Free/Pro; добавляются в вебе, используются в том числе на мобильном ⚠️ | Claude mobile — основной «телефонный» AI-клиент с записью через MCP |
| G3 | **MCP 2026-07-28:** stateless, DCR deprecated → CIMD, Tasks вынесены в расширение, MRTR вместо server-initiated elicitation | Сервер без сессий; auth поддерживает CIMD + DCR; не полагаться на elicitation и sampling |
| G4 | ChatGPT замораживает снапшот инструментов до ручного refresh; несовместимые изменения ломают вызовы | Схемы MCP-инструментов версионировать и менять только аддитивно |
| G5 | **MCP Apps:** в ChatGPT пока нет вызова инструментов из UI ⚠️ | Карточки Inbox в чате — бонус; решение принимается через обычный tool call или в нашем UI / Telegram |
| G6 | ChatGPT и Claude не ходят в приватную сеть (у OpenAI есть Secure MCP Tunnel) | Нужен публичный HTTPS endpoint для MCP + OAuth; админка остаётся за Tailscale |
| G7 | **Slack:** распространяемые вне Marketplace приложения получают 1 req/мин и 15 объектов на `conversations.history` | Open-source дистрибутив не может поставлять общий Slack app. Варианты: каждый пользователь создаёт своё internal app по инструкции, или используем официальный Slack MCP (нужно одобрение админа) |
| G8 | **LiteLLM** был скомпрометирован на PyPI (март 2026) | Supply-chain политика: pin + hash, Docker-образы, минимум зависимостей в ядре; важно для дистрибутива |
| G9 | **DBOS Conductor** (UI) проприетарный, self-host в проде только по лицензии | Activity / Runs UI пишем сами (он и так нужен для Activity Log) или берём Hatchet |
| G10 | Graphiti сам извлекает и правит граф через LLM; что делает `add_triplet` при противоречиях, не документировано | Graphiti только как проекция одобренных фактов; поведение `add_triplet` проверить руками |
| G11 | Бенчмарки памяти (LongMemEval и др.) насыщены и спорны | Выбирать проекции по своему мини-датасету сценариев, а не по README |
| G12 | Claude Managed Agents хранит состояние сессий у Anthropic и не подпадает под ZDR | Для корпоративной инсталляции облачные рантаймы, возможно, запрещены; нужен self-hosted рантайм (OpenCode / SDK в своём контейнере) |
| G13 | Self-host на VPS ≠ недоступность данных для провайдера; внешние LLM видят отправленное (из 02) | Политика «какие данные в какие модели» — часть deployment-конфига |

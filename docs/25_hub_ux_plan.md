# После MVP: хаб и удобство — план

> Ответ на QN1 (раунд 20): «Frood как хаб» и начать работу над UX — админка в духе современных консолей, удобный Telegram-бот, удобство первостепенно.
> Основание: исследования «Frood среди соседей» и «Frood как хаб» (H1–H19, HC1–HC5), веб-интерфейс N9′ ([15](15_inbox_attention.md) §9), каналы ([15](15_inbox_attention.md) §4), MVP ([17](17_mvp_plan.md), [18](18_implementation_log.md)).

## 1. Что меняется для человека

Сейчас Frood работает, но пользоваться им неудобно: админ-панель — одна страница с вкладками для отладки, вердикт ставится по одному, бот умеет связку, сводку и кнопки под записью Inbox. Польза памяти видна только тому, кто знает, куда смотреть.

Цель этапа — чтобы каждый день открывать Frood хотелось: утром в Telegram или на странице «Сейчас» видно, что изменилось и что ждёт решения; разбор пачкой занимает минуту; любое действие — одна-две кнопки, и его можно отменить.

## 3. Консоль (M8)

### 3.1 Как выглядит

Как консоли Vercel, Supabase, Cloudflare, Linear: слева — разделы, сверху — поиск и палитра команд (⌘K), в середине — таблица или лента, справа — панель подробностей, без перехода на другую страницу. Светлая и тёмная тема по системе. На телефоне — нижняя навигация и карточки вместо таблиц.

| Раздел | Что внутри |
|---|---|
| **Сейчас** | По проектам: действующие решения, сроки на две недели, кто за что отвечает, открытые вопросы, что изменилось за неделю. У строки — источник и история (H7) |
| **Inbox** | Лента записей с группировкой по источнику и проекту; разбор клавишами и пачкой; автоматически принятое помечено и отменяется (H5) |
| **Знания** | Поиск, сущности, утверждения с историей версий и источниками; то, что было Explorer (N9′) |
| **Источники** | Подключённые источники, клиенты (Claude, ChatGPT, Claude Code, Codex), каналы, модули: состояние, когда читались, подключить новое |
| **Автоматизации** | Джобы и расписания, запуски с логами и стоимостью, вопросы агентов |
| **Система** | Здоровье, бэкапы, логи, метрики, конфиг и его ревизии, токены, расходы |

### 3.2 Принципы удобства

- Главное действие видно сразу и делается одним нажатием; опасное — с подтверждением, остальное — с отменой (тост «Принято · Отменить»).
- Клавиатура: `j`/`k` по ленте, `a` — принять, `o` — оставить старое, `s` — отложить, `x` — выбрать, `⌘K` — к чему угодно.
- Пустой раздел подсказывает следующий шаг («Источников нет — подключите YouTrack или любой MCP-сервер»).
- У каждого объекта постоянный адрес; бот и сводка ведут прямо на него.
- Слова — действия, а не термины модели (HC4): «Принять», «Оставить старое», «Отложить», «Что изменилось»; «утверждение», «предложение», «вердикт» — только в подробностях.

### 3.3 Как устроено (U1)

- Одностраничное приложение на React + TypeScript, сборка Vite, стили Tailwind, компоненты shadcn/ui (Radix), таблицы TanStack Table, палитра `cmdk`. Это ровно то, на чём сделаны консоли из примера, — меньше всего своего кода для такого вида.
- Сборка встраивается в бинарник ядра, как сейчас `admin.html`: установка остаётся одним образом, Node нужен только при сборке (Docker и CI).
- Вход — тот же OAuth с PKCE клиентом `frood-admin`; адрес консоли — `/admin/` (под путём, если он есть).
- API — существующий `/v1`; чего не хватает (разбор пачкой, отмена, данные «Сейчас»), добавляется в ядро с тестами. Типы клиента — из описания OpenAPI, которое ядро начнёт отдавать (A2′).
- Строки интерфейса на двух языках, по языку браузера, как сейчас.

## 4. Telegram-бот (M8)

| Что | Как |
|---|---|
| Меню | Команды в меню Telegram (`/now`, `/inbox`, `/ask`, `/settings`) и постоянная кнопка меню |
| Связка | Ссылка `t.me/<бот>?start=<код>` из консоли — одно касание вместо `/link <код>` |
| Заметка | Любой текст или голосовое — заметка; ответ «Записал» с кнопкой «Отменить» и, для голосового, распознанным текстом |
| Вопрос | `/ask` или «?» в начале — ответ из памяти со ссылками на источники (нужна модель — тратит аккаунт из конфига) |
| Inbox | Карточка: что было, что предлагается, откуда; кнопки «Принять / Оставить старое / Отложить / Подробнее»; после решения сообщение правится, а не копится |
| Пачкой | «Ещё 5 из YouTrack — Принять все / Разобрать по одной» |
| Сводка | Утренняя сводка с кнопками по разделам и «Открыть в консоли» |
| `/now` | Короткая «Сейчас»: сроки на неделю, ждёт решения, что изменилось |
| `/settings` | Тихие часы, язык, что присылать — кнопками |

Принципы те же: одно касание, отмена, сообщения правятся, а не множатся; длинное — ссылкой в консоль.

## 5. Проверка

- Консоль: компонентные тесты и сквозные сценарии в браузере (Playwright) в CI: вход, разбор пачкой с отменой, «Сейчас», мобильная ширина, тёмная тема.
- Бот: тесты модуля с поддельным Telegram, как сейчас, плюс живой прогон на вашем боте.
- Живая проверка на сервере: неделя пользования, ваши замечания — правками по ходу.

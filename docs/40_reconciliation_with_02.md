## Совпадает (независимо пришли к тому же)

- Своё доменное ядро как источник истины; memory-движки — проекции. Graphiti не получает права менять канон без ревью.
- Разделение Observation → Proposal → Decision → Assertion; Inbox как pull requests.
- Bitemporal-модель (valid time + recorded time); supersede вместо удаления.
- Postgres + outbox + фоновый worker, без Kafka / NATS / k8s на старте.
- Модульный монолит: capability-контракты, provider, deployment; Core стартует без LLM, графа и чата.
- Отдельные personal / corporate deployments одного кода.
- Runtime агента отдельно от определения агента.
- Checkpoint последней обработанной позиции вместо «за вчера».

# Telegram Mini App — предложение

> Статус: сделано (раунд 27 принят). Выйдет в 0.1.14; на сервере ещё не проверено.
> Основание: отзыв автора 07.11 — «чат в телеге имеет очень ограниченный интерфейс, может надо телег-апку сразу делать?». Сводка из раунда 26 остаётся; Mini App даёт ей и Inbox нормальный экран.

## 0. Что это

Mini App — веб-страница, которая открывается кнопкой прямо внутри Telegram, на весь экран, не выходя из чата. Telegram передаёт странице, кто её открыл, с подписью, которую можно проверить. Сообщения в чате остаются короткими, а разбирать, читать и решать удобно на экране Mini App.

В чате сейчас тесно: только текст, кнопки одна под другой, длинные тексты режутся. Mini App снимает эти ограничения.

## 1. Предлагаю

**M1. Mini App — мобильный вид консоли Frood.** Это не новое приложение: те же страницы консоли («Сейчас», Inbox, «Знания»), собранные под телефон. Открывается из бота тремя путями:
- кнопкой меню бота «Frood» рядом с полем ввода;
- кнопкой «Разобрать» в сводке — сразу на список того, что ждёт;
- кнопкой «Подробнее» под карточкой — сразу на эту запись.

**M2. Вход по подписи Telegram, без пароля.** Frood проверяет данные запуска (`initData`) по открытому ключу Telegram (Ed25519). Токен бота ядру для этого не нужен, он остаётся только в модуле бота. Человек — тот, чей Telegram привязан к Frood. Сессия короткая и живёт только внутри Mini App. Непривязанный Telegram не входит никуда.

**M3. Только с публичным адресом.** Telegram открывает Mini App лишь по адресу https. У сервера он есть, ноутбуку нужен туннель (T1). Без публичного адреса всё как сейчас: кнопки в чате.

**M4. Как часть Telegram.**
- Цвета берутся из темы Telegram: светлой или тёмной, как у человека.
- Кнопка «Назад» — системная, главное действие — большая кнопка снизу экрана, касания отзываются вибрацией.
- Ссылки на тикеты открываются в браузере, Mini App при этом не закрывается.

Как выглядит разбор на телефоне — на странице ревью: карточка находки с заголовком, меткой тикета-ссылкой, цитатой и кнопками «Принять», «Не то», «Позже». Между карточками — смахиванием.

## 4. Как сделано

**Адрес.** Mini App — та же консоль под `/admin/m/` (`https://<адрес>/admin/m/`). Отдельной сборки нет: консоль подгружает экраны Mini App, только когда открыт этот адрес. Для этого адреса сервер отдаёт свою политику безопасности: можно загрузить скрипт Telegram и показать страницу во фрейме веб-версии Telegram. У остальной консоли всё строго, как было.

**Вход (M2).**
- Бот при запуске сообщает ядру свой id вместе с адресом для привязки: `PUT /v1/channels/{channel}/about` с полем `bot_id`.
- Mini App отправляет данные запуска на `POST /oauth/telegram {init_data}`. Ядро проверяет подпись Ed25519 открытым ключом Telegram по id бота. Токен бота ядру не нужен.
- Данные старше суток не принимаются, повторяющиеся поля — тоже.
- Человек — тот, к кому привязан этот Telegram, и он должен быть в списке допущенных.
- Сессия: один токен доступа на время `auth.access_token_minutes`, без токена обновления. Права: читать, записывать, предлагать, решать; без `admin` (QM2). Когда токен истекает, Mini App входит снова теми же данными запуска.
- В журнале действия видны как `user:<id>/via/frood-telegram`.

**Экраны (QM1 — б).**
- Главный:
  - поиск;
  - сводка: важное, сроки, принятое (свёрнуто после четырёх строк), кнопка «Принять находки без проверки»;
  - список «Ждёт вас»: сначала срочное, потом новое.
- Карточка записи — та же, что в консоли. Между карточками — смахиванием, «Принять» — большая кнопка Telegram внизу. Решение можно отменить из всплывающего сообщения.
- Поиск: недавнее, пока ничего не введено, затем результаты.
- Карточка знания: история, вложения, источники с цитатами (у заметки без цитаты — начало её текста) и ссылками; «Верно» — большая кнопка внизу. Источники отдаёт новый `GET /v1/assertions/{id}/sources`.

**Как часть Telegram (M4).**
- Цвета из темы Telegram, светлой или тёмной; меняются вместе с ней.
- Системная кнопка «Назад».
- Вибрация при решении и смахивании.
- Ссылки открываются в браузере через `openLink`, Mini App остаётся открытым.

**Бот (M1, QM3 — а).**
- Кнопка меню «Frood» рядом с полем ввода открывает Mini App.
- Под карточкой вместо ссылки «Подробнее» на консоль теперь «Открыть в Frood»: эта запись в Mini App.
- Под сводкой — «Открыть в Frood»: главный экран.
- Остальные кнопки в чате прежние.
- Всё это — только с публичным адресом https (M3); без него бот как раньше.

**Проверено:**
- тесты ядра: подпись Telegram, вход привязанного человека, отказ непривязанному, чужому боту и тому, кого нет в списке; у сессии нет `admin`; разные политики безопасности у Mini App и консоли; источники знания;
- тесты бота: id бота, кнопка меню с публичным адресом и без него, «Открыть в Frood» под карточкой и сводкой;
- браузерный тест консоли: Mini App с заменой скрипта Telegram — цвета темы, большая кнопка, «Назад», «Отложить», поиск, карточка знания с источником;
- вручную в браузере на ширине телефона: смахивание, кнопки Telegram, русский язык.

**Не проверено:** настоящий вход из Telegram — подпись Telegram в тестах заменена своим ключом. Проверить можно только на сервере после выпуска.
